# Waveform Viewer Pro — 19 项问题评估与 P0+P1+P2 全面修复方案

基于对工程 TypeScript 源码的逐项核查，本方案对用户提出的 19 项代码审查清单给出真实性评估与分类定性，并落地**全部 P0 核心计算缺陷、P1 热模型可信度问题及 P2 数据/安全/性能实质缺陷**的修复。

## User Review & Critical Decisions

> [!IMPORTANT] 以下核心产品与物理规则已根据您的确认锁定，方案将严格按此执行：

- **修复范围**：覆盖全部 P0、P1 计算问题及 P2 实质缺陷（注：当前工程源码已是清晰的模块化 TypeScript 架构，并非单文件混编，清单中压缩函数名来自离线 HTML 打包产物，本次直接在模块化源码中根治全部实质缺陷）。
- **热计算物理守恒**：启用“严格物理守恒”策略——功率计算失效/为零时**直接阻断反演**并报错（严禁静默回退 `40 W` 或沿用旧值）；热功耗递推前强制非负钳位（$P_{\text{diss}} \ge 0$），避免负开关/负回馈功率进入 RC 热网导致结温异常下降。
- **Filter 与 Math 规则**：`Filter` 覆盖应用始终基于原始备份 `refV` 重算，保证连续点击 `Apply` 幂等不叠加衰减；`Math` 除零、负数开平方等数学未定义区间严格输出 `NaN`（不静默变 `0`），非均匀/全通道支持时间轴对齐与量纲推导。
- **FOC Demo 与单阶热模型**：加载 FOC 3 相 Demo 时自动重置为内置 `DEFAULT_FOC_MODEL` 并在界面显式标明模型来源，消除历史 `activeCauerStages` 串扰；单阶 Cauer 拆分添加显式非物理估算警示标识。

## 3. 核心工程决策与权衡

1. **任意长度 FFT 方案选择：Bluestein (Chirp-Z) vs 强制零填充**
   - *选择策略*：对于长度为非 $2^k$（如 1000 点）且在交互阈值（262,144 点）内的捕获数据，采用精确 **Bluestein $O(N\log N)$ FFT 算法**计算原生 $N$ 点加窗频谱；同时当外部显式配置 `zeroPadding > 1` 时，对完整 $N$ 点在 Bluestein/Radix-2 中扩展频谱网格。
   - *原因*：Bluestein 在精确 2 次幂长度时退化为标准 Radix-2 FFT（保持已有全部频谱幅值与频率精度测试严格一致），在非 2 次幂长度时则零截断丢弃任何采样点，且无需在尾端强行补零扭曲相干增益与噪底。
2. **时间加权 RMS / Average 与均匀快速路径**
   - *选择策略*：当通道元数据判定为均匀采样且无 NaN 空洞时保留高效样本统计（数值与均匀积分等价）；一旦检测到非均匀采样、抖动或变步长（如 LTspice 自适应步长），自动切换为相邻有效样本间的梯形积分 $\int x\,dt / \int dt$ 与 $\sqrt{\int x^2\,dt / \int dt}$。
   - *原因*：兼顾示波器大数据量高速计算与开关电源变步长仿真数据的物理准确性。
3. **CSV 带单位单元格与列头单位联动换算**
   - *选择策略*：将列头提取的基准单位（如 `V` 或 `mV`）传入单元格解析逻辑；遇到 `12 mV` 写入基准为 `V` 的列时自动乘 `1e-3` 转为 `0.012`，写入基准为 `mV` 的列时保持 `12`。同物理量纲跨前缀兼容转换。
   - *原因*：防止混用示波器导出前缀时产生 1000 倍量级错误。

### 各子系统改动规划
- **电热与损耗引擎**：
  - `computeLossWithDeskewAndEoss` 与 `simulateFosterZoh` 在输入 RC 递推前将驱动热功率钳位至 $\max(0, P)$（同时保留原始有符号电能量对比指标）；
  - `computePowerSummary` 保留净有功均值 `avgPowerW` 并新增绝对热耗散均值 `avgDissipationW`；
  - `readAndApplyPowerChannel` 使用 `avgDissipationW` 计算热功率且禁止 `0 -> 40 W` 假填充，`runDeconvolution` 在功率读取返回 `null` 或 $\le 0$ 时直接中止反演并提示；
  - `loadFoc3PhDemoTab` 重置使用 `DEFAULT_FOC_MODEL` 并刷新热模型来源标识；单阶 `splitCauerToFocModel` 标记 `isHeuristicSingleStageSplit` 并在界面警告。
- **滤波器与数学表达式引擎**：
  - `applyFilterToChannel` 原位滤波优先读取 `srcCh.refV`（若首次滤波则先锁定 `refV`），Filter 工作台增加“还原原始波形”按钮；
  - `mathParser` 重写数字词法分支与时间对齐插值逻辑，除零与负开方/无效幂严格写入 `NaN`，依据运算结构推断合理单位（如 `W`、`A`、`V/s` 等）。
- **采样质量、FFT 与测量**：
  - `analyzeSamplingQuality` 接收并统计信号内部 `NaN` 数、重复/倒序时间戳数及合成时钟标志；`csvParser` 重采样后在元数据保留 `rawGapCount`/`wasResampledFromGaps` 等溯源信息；
  - `computeFFT` 引入 Bluestein $O(N \log N)$ 算法消除截断丢点，内部 `NaN` 改用线性插值，附带非均匀采样警示；
  - `computeMeasurements` 在非均匀时间轴下启用梯形时间加权积分计算 `average` 与 `rms`。
- **导入导出、会话安全与性能**：
  - `csvParser` 支持基于列单位的带后缀数值换算；`exportWaveformCSV` 按基准时间轴插值对齐所有可见通道，缺值写空串；`exportSpectrumCSV` 输出动态通道真实单位表头；
  - `session.ts` 增加版本、数组长度一致性和引用存在性校验；全局 UI 渲染拼接加入 `escapeHtml` 净化；`uiController` 的鼠标拖动/悬浮高频重绘通过 `requestAnimationFrame` 合帧节流。
