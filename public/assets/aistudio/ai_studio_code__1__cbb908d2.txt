## 1. 关于 `PyRth` 移植的技术边界与取舍（架构基准）

### ✅ 采纳并实现
1. **两阶段去偏 L1 稀疏去卷积（Relaxed LASSO）**：补充/替代现有的稠密 L2 NNLS，获得物理意义清晰的稀疏 $\tau$ 谱。
2. **自动化 $\lambda$ 选择**：使用简化 L-curve 拐点法或交叉验证（CV），避免用户手动调参。
3. **阻抗域模型降阶（$2 \sim 6$ 阶）**：将有效极点在阻抗域重拟合为 $2 \sim 6$ 阶紧凑 Foster 网络，在 `Float64` 下采用时间尺度归一化转为 Cauer 梯形网络，并导出标准 LTspice `.subckt`。
4. **低阶实用结构函数（$C_\Sigma$ vs $R_\Sigma$）**：针对实测窗口可分辨的 $2 \sim 3$ 个物理层级展示结构函数。
5. **复用现有模块**：复用已有 ZOH 闭环结温正演与 Dynamic SOA 校验，结果以标准 `Channel`（`W` / `°C`）注入 `OscilloscopeApp`。

### ❌ 明确裁剪（严禁实现）
1. **不做 $60 \sim 150$ 阶超高阶连续结构函数**：实测窗口（通常几十秒）物理上无法分辨芯片微秒级热容，强行算 150 阶画出来全是测量噪声伪影。
2. **严禁使用 JS `BigInt` 模拟 `PyRth` 的 `mpfr` 任意精度**：
   - `PyRth` 高阶路径依赖 `transient_mpfr_utils`（`build_mpfr_foster_impedance`、`normalize_rational_polynomials`）在浮点有理多项式上运算。
   - JS `BigInt` 是定点数，无法同时覆盖 $10^{-900} \sim 10^{900}$ 系数跨度，且除法极慢。$2 \sim 6$ 阶下归一化 `Float64` 已足够（Relative Error ~ `0.00e+0`），若极端病态最多使用约 60 行 `double-double` 兜底，不写 `BigInt` 浮点库。
3. **不搞无基准对照的“1:1 贝叶斯去卷积”口号**：`PyRth` 源码中对应函数为 `transient_core.py` 的 `perform_bayesian_deconvolution`；任何与 `PyRth` 对齐的宣称必须基于同输入曲线的数值对齐验收。

## 2. Phase 1：升级 `thermalEngine.ts` 与热工作台 UI

### 2.1 LASSO 去卷积与 5 个必防数学陷阱
1. **对数分箱采样（或粗步进原样时间戳）**：
   - 若数据点密集（如示波器采样 $\ge 300$ 点），必须先做**对数分箱均值重采样**（每个十倍频程约 $20 \sim 30$ 点），消除线性采样下长尾对毫秒极点的权重碾压；**无样本落入的空分箱直接跳过**，禁止线性插值捏造数据。
   - 若有效样本数较少（如 $\Delta t = 1\text{ s}$ 记录仪数据，点数 $< 300$ 或步长有轻微抖动），直接基于真实非均匀时间戳 $t_i - t_0$ 构建拟合矩阵 $A_{ij} = 1 - e^{-(t_i-t_0)/\tau_j}$。
2. **动态 $\tau$ 网格上下限保护**：
   - $\tau_{\min} = \max(10^{-4}\text{ s},\; 0.5 \cdot \Delta t_{\text{med}})$：大步进数据（如 1s）自动禁止生成毫秒级虚假极点。
   - $\tau_{\max} \le 3 \cdot t_{\max}$：若末端未达热稳态，防止求解器用超大 $R$ 配超大 $\tau$ 虚高估稳态热阻，并在 UI 弹出非阻塞警示条。
3. **列范数平衡 + 两阶段去偏（消除 L1 收缩偏低）**：
   - 对矩阵 $A$ 执行列范数平衡后再跑非负坐标下降（$R_j \ge 0$）。
   - LASSO 仅负责**选峰** $\to$ 对相邻非零网格执行**能量加权质心合并** $\to$ 仅保留合并后的峰 $\tau_k^*$ 执行一次**无 $\lambda$ 惩罚的纯 NNLS 重拟合**，确保 $\sum R_k$ 无偏守恒。
4. **支持 `Heating` 与 `Cooling` 双输入模式 + `Auto t0`**：
   - **Heating**：$Z_{th}(t) = (T(t) - T_{\text{base}}) / P$。
   - **Cooling（实验室 TSEP/断电降温常用）**：$Z_{th}(t) = (T_j(0) - T(t)) / P$，支持设置起始电瞬态盲区 $t_{\text{blank}}$，并执行 **$\sqrt{t}$ 线性回归外推**还原 $T_j(0)$。
   - **时间切片与 $t_0$ 识别**：支持 `Entire`、`View`、`Cursors [X1 ~ X2]`，并提供 **Auto $t_0$ 检测**（识别室温基线均值 $T_{\text{base}}$ 与温升/降温起跳拐点），禁止硬编码假设数组第 0 个点就是 $t=0$。
5. **大步进数据（如 $\Delta t = 1\text{ s}$）平滑拟合曲线回注**：
   - 支持将多指数解析公式 $T_{\text{fit}}(t)$ 按 $10\times \sim 20\times$ 加密重采样生成连续光滑 `Channel` 注入主示波器（多指数物理单调、在阶跃处零过冲，优于 `Sin(x)/x` 三次样条），与原始离散点同屏叠加对比。

### 2.2 降阶、标定条件区分与 LTspice 网表规范
1. **阻抗域降阶（$N \in [2, 6]$）**：将有效谱在阻抗域重拟合为指定阶数 $N$ 的 Foster 网络，转为 Cauer 梯形网络并验证 $\sum R_{\text{Foster}} \approx \sum R_{\text{Cauer}}$（相对误差 $< 10^{-6}$）。
2. **Cauer 网表电容接地硬性规范（物理防错）**：
   - 导出的 Cauer `.subckt MOS_THERM TJ TAMB` 中，**所有热容 $C_1 \dots C_n$ 必须接至全局参考节点 `0`（绝对温度参考，单位 °C）**，仅末级热阻 $R_n$ 接至 `TAMB`/`TC` 端口；**严禁把 Cauer 电容接在浮动的 `TAMB` 节点上**。
3. **1-MOS vs 6-MOS 标定接口预留**：
   - 在反演设置中提供标定模式标注：`单管独立加热 (1-MOS)` vs `三相6管同步对称加热 (6-MOS)`，并允许用户将高阶/多阶网络按时间常数边界（如 $\tau_{\text{split}}$）拆分为 **单管快阶 `ZthJC`** 与 **共板慢阶 `Zth_board`**。

### 2.3 单管损耗剥离校准（完善 Tab 2）
- 为 `Vds` × `Ids` 瞬态损耗计算加入：**`Deskew (ns)` 探头延时亚采样线性插值对齐**，以及 **`Eoss` 储能剥离**（关断扣除 $E_{oss}$，开通加回 $E_{oss}$）。
- 注入主示波器 `P_loss (W)` 与闭环 `Tj (°C)` 后，自动切换 `tab.separateView = true` 并自动向底部 `Measurement Strip` 添加 `Tj Max` 与 `P_loss Mean`。

### 2.4 热工作台 UI 布局规范（贴合暗色仪表风 `#12161c` / `#0c0f13` / `#222933`）
- **入口**：底部工具栏增加 `MOS Thermal` 按钮，弹出 4 标签页工作台（Phase 1 先实现前 3 个，Phase 2 接入第 4 个）：
  1. `热阻反演与网表`
  2. `损耗剥离与 Tj(t)`
  3. `Dynamic SOA`
  4. `BLDC FOC 6-MOS 热评估`（Phase 2）
- **Tab 1 采用“左窄控（~320px）+ 右宽图（自适应）”分栏**：
  - **主图**：离散实测点/线 + 平滑拟合曲线，右上角提供 **`Lin-t` / `Log-t` 一键切换**及 $R^2$、RMSE、$R_{th,total}$ 读数；上方设非阻塞状态条（提示未达稳态或大步进可信时间尺度）。
  - **副图（分段切换）**：`τ 时间常数谱柱状图` | `累计结构函数` | `拟合残差 ΔT`。
  - **参数与联动**：支持“从主屏光标 `[X1~X2]` 导入区间”、“从功率通道读取 $P_{\text{avg}}$”；输出 RC 表格按 $\tau$ 尺度自动附参考物理标签（`<10ms 芯片/焊料`、`10ms~1s 封装/基板`、`>1s PCB/散热器`）；提供 `复制 SPICE`、`下载 .lib`、`应用到 Tj 仿真`、`注入平滑拟合曲线到示波器`。

## 3. Phase 2：BLDC / PMSM FOC 6-MOS 专精热评估模块（建议新增 `src/modules/focThermal.ts`）

解决 4 通道示波器无法同时测 6 颗管 $V_{ds}$、且 FOC 下存在共板互热与堵转不均的问题：

### 3.1 6-MOS 星型共板热耦合网络
- 拓扑：`Q1..Q6`（`AH, AL, BH, BL, CH, CL`）各自拥有独立的快阶 **`ZthJC`**，共同汇入一个 **共享 PCB/散热器节点 `T_board`**，再经共享 **`Zth_board`** 通向 `TAMB`。
- 求解器：采用 $O(N)$ 耦合 ZOH 离散状态空间推进，每步用各管独立当前结温 $T_{j,m}[k]$ 实时更新各自的 $R_{DS(on)}(T_{j,m}[k])$，支持导出 **7 端口 LTspice 网表 `.subckt INV_6MOS_THERM Q1 Q2 Q3 Q4 Q5 Q6 TAMB`**。

### 3.2 仅用 FOC 电流与母线电压推算 6 管瞬态损耗与结温
- **输入**：示波器里的相电流通道 `Ia, Ib, Ic`（或仅选 `Ia, Ib`，自动算 `Ic = -Ia - Ib`）+ `Vbus` 通道（或恒定母线电压）；以及 MOS 参数（$R_{on,25^\circ\text{C}}$、温度系数 $\alpha$、$V_{SD}$、$Q_{rr}$、参考开关能量 $E_{on,\text{ref}}/E_{off,\text{ref}} @ V_{\text{ref}}, I_{\text{ref}}$）、控制参数（调制方式 `SVPWM / SPWM / DPWM`、载波频率 $f_{sw}$、死区 $t_{dead}$、调制比 $m$ 或已导入的占空比通道）。
- **物理损耗归属（同步整流 + 第三象限死区）**：
  - 依据电流符号 $i_x(t)$ 区分主动硬开关管与同步续流管：
    - 当 $i_x(t) > 0$：上管承担导通 $i^2 R_{on}(T_{HS}) d_x$ + 硬开关损耗 $f_{sw}\left[(E_{on}+E_{off})\frac{V_{bus}}{V_{\text{ref}}}\frac{|i|}{I_{\text{ref}}} + Q_{rr}V_{bus}\frac{|i|}{I_{\text{ref}}}\right]$；下管承担续流导通 $i^2 R_{on}(T_{LS}) (1-d_x)$ + 死区体二极管导通 $|i| V_{SD} (2 t_{dead} f_{sw})$（下管 ZVS 无硬开关损耗）。
    - 当 $i_x(t) < 0$：上下管硬开关与体二极管角色**对调**。
    - 若选择 **`DPWM` 断续调制**：在某相被钳位至 $d=1$ 或 $d=0$ 的 60° 扇区内，开关与死区损耗置 `0`，仅保留导通损耗。
- **输出**：将 `Tj_AH..Tj_CL`（°C）及 `P_inv_total`（W）注入主示波器，并在面板给出每颗管的 **$T_{j,\text{avg}}$、$T_{j,\text{peak}}$ 及低频电周期结温纹波 $\Delta T_{j,\text{ripple}}$**。

### 3.3 FOC 堵转 / 零速扫角极值分析 & 固件 $I^2t$ 保护反推
- 输入堵转峰值相电流 $I_{pk}$（或 $I_q$）、允许最高结温 $T_{j,\text{limit}}$（如 $150^\circ\text{C}$）及初始板温。
- 在 $\theta_e \in [0^\circ, 360^\circ)$ 自动扫描最恶劣锁相角度（固定直流偏置 $I_{pk}\cos\theta_e$ 下单相承担 $2\times I_{rms}^2$ 发热量）。
- 输出：最危险管号与角度、稳态是否安全、若超温给出 **安全堵转持续时间 $t_{\text{safe}}$（秒）** 及对应的 **固件 $I^2t$ 热积分报警阈值**。

### 3.4 控制策略扫参对比（What-If 权衡）
- 一键对比 `SVPWM vs DPWM` 温升差异，并支持输出 $T_{j,\max}$ 随载波频率 $f_{sw}$ / 死区 $t_{dead}$ 变化的权衡曲线。

## 4. 验证与验收标准（必须全部通过才能算完成）

1. **自检测试套件（Self-Test）**：
   - **LASSO 稀疏性与无偏性**：对含高斯噪声的合成 3 阶 RC 温升曲线（Heating & Cooling 各一组），验证 LASSO 非零峰数显著少于稠密 NNLS，且去偏重拟合后总热阻误差 $< 1\%$。
   - **大步进（1s）数据测试**：输入 $\Delta t = 1\text{ s}$、$t_0$ 在第 10 秒才起跳的模拟热电偶数据，验证 `Auto t0` 正确识别起跳点、$\tau_{\min} \ge 0.5\text{ s}$ 无虚假快极点、且生成光滑平滑曲线无过冲。
   - **$\sum R$ 守恒与 Cauer 接地检查**：验证降阶 Foster 与转出的 Cauer 总热阻相对误差 $< 10^{-6}$；校验导出的 Cauer `.subckt` 网表中所有电容均接节点 `0`。
   - **FOC 6-MOS 对称与符号切换检查**：对称三相正弦电流输入时 6 管平均功耗一致；电流反向时硬开关与体二极管损耗正确对调；堵转 $\theta_e = 0^\circ$ 时 A 相峰值发热等于均值的 2 倍（相比同幅值交流有效值分布）。
2. **PyRth 外部基准对齐验证**：
   - 使用同一份标准温升曲线与 Python `PyRth` 跑出的基准结果（`tau`、`R_i`、总热阻）对照：主 $\tau$ 峰位置对齐，总热阻偏差 $< 1\%$。
3. **打包验收**：
   - 执行 `npm run build` 顺利生成单文件 `waveform-viewer-pro.html`，无 TS 错误，打开离线页面各功能自检全绿。
