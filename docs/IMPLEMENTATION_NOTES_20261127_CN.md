# WAVE-Test 软件层完善记录（2026-11-27）

本轮基于 `WAVE-Test-main-software-models-20261125.zip` 的源码完成，重点处理 FOC DynoLab、MOS Thermal、Compare 和多 Excel 合并导入。本文区分软件已实现内容与仍需要实物数据验证的内容。

## 1. FOC DynoLab：把通用起算假设与电机实测参数分开

- 新增“驱动起算值”按钮，只填入低压 BLDC 逆变器的演示级起算假设（如空载电流、逆变器效率、死区、开关频率、线路电阻、二极管压降等）。不会覆盖电机铭牌/标定参数，也不会写入 MOS 的 Rds 或开关损耗数据。
- 电机极对数、Ke、线间电阻、线间电感、绕组温度等仍要求来自具体电机资料或实测。不能用通用推荐值替代电机本体参数。
- β 饱和系数、P0(n) 损耗拟合系数允许不填；不填写时关闭对应修正项，并产生模型边界提示，不把“未建模”解释成“物理效应不存在”。
- 驱动侧次要参数采用中性值/可选输入：未启用的压降或损耗项不偷偷叠加假设损耗。逆变器效率 1.0 作为中性值，不再被强制夹到低于 1。
- 新增提示：β 或 P0 项为零/未标定时，扭矩和高速效率估算可能偏乐观。
- 修正 Dyno 标定 SVD 数值矩阵类型，修正 XY 频率分析使用不存在的采样间隔字段，改为读取实际的中位采样间隔。

## 2. MOS Thermal：空值不再冒充器件数据

- 新增“应用低压 Si MOS 起算值”按钮。该选项只用于建立 48V 级硅 MOS 的控制/工况起点，不会自动填入 Rds(on)、Eon/Eoff、Qrr、Eoss、Rg 或 PCB 热网络。
- Esw、Eoss、Qrr、Rg 可保持空白。空白代表对应损耗/效应不纳入当前计算，并提示可能导致结温低估；不再用看似精确的占位数字伪造器件数据。
- UI 中的 Rds(on) 示例值不是通用推荐值；只有用户确认与具体 MOS 数据手册或实测一致后才作为已确认输入，编辑后需要重新确认。
- RθJC 单位标注修正为 °C/W；导入 Cauer 热网络时要求物理 RθJC 锚点，不能用时间常数分配比例代替器件结壳热阻。
- DPT 矩阵中的 Tj、Rg_on、Rg_off 改为必填且需要用户确认真实测试条件。任一数值变化都会撤销确认；不再静默用 Tj=25°C 或 Rg=4.7Ω 填充。
- DPT 查表预检查不再把环境温度冒充结温。预检查使用 LUT 结温区间中值，仅用于检查数据覆盖；运行时每颗 MOS 的查询温度仍由六管热模型逐步估算，超出实测 LUT 范围会拒绝作为有效插值结果。
- 关键模型修复：Rg_on 与 Rg_off 是独立的查表维度。Eon/Qrr 按 Rg_on 轴插值，Eoff 按 Rg_off 轴插值；其中一侧固定、另一侧变化时，不会把两者误判为一个共同的 Rg 轴。若实际查询值超出固定侧实测范围，仍标记越界。
- Cauer 求解器状态更新改为显式可变状态对象，避免闭包更新导致 TypeScript 控制流类型误判。导入提示使用应用支持的状态类型。

## 3. Compare：先明确对齐，再判断差异是否有效

- 新增最低覆盖率设定：50%、80%、95%、99%，默认 80%。有效重叠覆盖率低于门槛时，不允许输出 PASS。
- 单条参考曲线可以直接编辑 Δt（秒），并支持小步进、t0 对齐、边沿对齐、峰值对齐和互相关自动对齐。
- 增加时间尺度预设，包括 1×、ms/s、μs 和匹配时间跨度；保留去直流、容差模式与容差带。
- 比较行继续显示时间范围、采样间隔、Δt、覆盖率、相关性/相似度、RMSE、MAE、最大差值与容差状态，便于先判断数据是否可比，再解释差异。
- 最低覆盖率属于判定质量门槛，不代表仪器精度，也不替代采样带宽、探头延迟、触发同步和测量不确定度分析。

## 4. 多 Excel：多个文件/工作表合并到同一 Scope 标签页

- 支持多文件、多工作表的选择结果合并为一个 Scope 标签页；通道名包含文件名和工作表名，映射为不同通道。
- 默认“保留源时间坐标”：每个通道保留自己的时间数组和非均匀采样特征，不强制重采样或插值；显示层允许多个不同采样时间基准并存。
- Excel 日期时间列恢复绝对时间坐标，Excel 1900/1904 日期系统均处理；纯数值时间保留其原始时间坐标。
- `HH:MM:SS` 没有日期时只作为日内时刻处理并提示歧义；不能证明来自同一天。没有时间列、由软件补造的合成时钟，不会被当成跨文件同步时钟计算公共覆盖。
- 混合绝对日期时间与相对数值时间坐标不会被误判为有公共重叠区间。
- 可选“首样本对齐 t=0”：仅平移每条曲线的显示时间与 rawT，不修改电压、电流等采样值，也不插值。该操作是用户提供的对齐假设，不是共同触发同步的证明。
- 合并提示显示公共时间窗口、最小覆盖率或无公共重叠，并对时钟来源、日期缺失、非单调时间轴和同步基准不明给出警告。
