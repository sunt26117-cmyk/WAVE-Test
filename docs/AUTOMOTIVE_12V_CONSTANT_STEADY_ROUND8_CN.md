# WAVE-Test Round 8：六管恒定工况损耗分配修正

## 本轮目标

继续以 12V 汽车 BLDC FOC 为边界：六颗 MOS 同型号、共用同一套电气参数；Vbus 典型 13.5V、评估范围 9～16V；只处理固定工作点的六管平均损耗与稳态结温，不扩展动态 FOC。

## 1. 修复死区导通损耗在上下管之间的错误分配

位置：`src/modules/focThermal.ts`，`computePhaseMosLosses()`。

此前模型将完整 `2 × tDead × fsw` 从某一侧 MOS 的沟道导通占空比扣除，另一侧不扣除。这种算法在上下管 Rds 相同的情况下，可能保持单个半桥的总沟道导通损耗近似不变，但会把导通损耗从一颗 MOS 转移到另一颗 MOS，造成单管损耗与结温分布偏差：

- 正相电流：高侧沟道导通损耗偏高、低侧偏低；
- 负相电流：低侧沟道导通损耗偏高、高侧偏低。

修正后，每个有效 PWM 周期的两个死区边沿分别处理：

- `δ = tDead × fsw`：单个边沿死区占空比；
- `D_H,cond = d − δ`；
- `D_L,cond = 1 − d − δ`；
- `D_dead = 2δ`。

死区期间的体二极管归属仍按电流方向判断：

- `I_phase >= 0`：两段死区均计入低侧体二极管损耗；
- `I_phase < 0`：两段死区均计入高侧体二极管损耗。

因此，对有效 PWM 脉冲，半桥占空比分配满足：`D_H,cond + D_L,cond + D_dead = 1`。上下管的沟道导通损耗不再发生一边多扣、另一边不扣的偏移。

## 2. 对窄脉冲死区边界采取拒绝计算

若指令侧脉冲宽度不大于一个边沿死区占空比（`d <= δ` 或 `1-d <= δ`），则实际行为取决于 MCU/驱动器的窄脉冲删除、死区补偿及最小脉宽设置。稳态平均模型不猜测该行为，直接拒绝该工作点，并提示确认实际 PWM/gate 时序或导入实测 duty/gate 波形。这样避免因假设脉冲被抑制而虚构导通、开关或体二极管损耗。

## 3. 修复严格类型检查中的 DPT 输入联合类型收窄问题

位置：`src/modules/dptAnalyzer.ts`，`interpolateDptSwitchingLoss()`。

把数字 Vbus 与对象形式的 `DptOperatingCondition` 改成显式分支构造，避免 TypeScript 7 在联合类型收窄时把对象类型残留到 `vBusV`。这不改变运行时插值逻辑，只修复严格类型检查。

## 4. 新增回归

新增三项直接针对半桥单管分配的测试：

1. 正/负相电流分别核对高侧、低侧导通占空比和体二极管损耗归属，并核对 `P_H + P_L` 的半桥损耗守恒。
2. 检查窄脉冲宽度不大于死区时，模型明确拒绝该工况，而不是假设 MCU 的脉冲删除行为。
3. 对 5%～95% 的正常调制度占空比按 5% 步进，分别遍历正/负相电流，验证死区分配与半桥总损耗守恒。

## 当前模型仍然明确保留的边界

- 标量 `Eon+Eoff` 仍按参考 V/I 线性缩放，适合初步估算；多工况 DPT LUT 优先。
- Qrr 与 Eoss 是否包含在 Eon/Esw 中，仍必须按数据手册定义或 DPT 测量口径设置防重复开关，不能自动猜测。
- Eoss 单点仍采用 V² 近似；优先导入真实 `Eoss(V)` / `Qoss(V)` / `Coss(V)` 曲线。
- 12V 边界结果是固定电流/目标基波假设的敏感性分析。9V 电压能力不足时，不输出虚假的损耗和结温。
- 六管共用电气参数；每管损耗差异来自电流/占空比/开关状态及热路径，不增加六套 MOS 参数表。
- 模型尚未由目标 MOS 的 DPT、目标 PCB 热测与电机台架数据标定，不能替代热设计签核。
